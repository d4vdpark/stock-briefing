# Morning Market Brief

모바일과 PC 모두에서 예쁘게 보이는 주식 이슈 요약 원페이지 대시보드를 만들어줘.

상단에는 '오늘의 출근길 주식 핵심 브리핑'이라는 타이틀과 오늘 날짜가 들어가고,

메인 화면에는 카드 형식(Grid 또는 List)으로 종목명, 등락률, 그리고 '왜 올랐는지'를 요약해 주는 3줄 텍스트와 핵심 태그(#호재, #실적발표 등)가 깔끔하게 정렬되어 보여야 해.

전체적인 무드는 모던하고 신뢰감 있는 다크/라이트 모드 친화적인 미니멀리즘 디자인으로 해줘
